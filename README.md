# Task-2-ComPract-2
Навчальне завдання з комп'ютерного практикуму №2 (завдання 2).

## Опис
Програма мовою C++, яка розраховує оплату робіт залежно від типу виконаної роботи (A, B або C): нараховану суму, суму податку та суму до видачі.

## Умова завдання
Оплата робіт залежить від типу виконаної роботи (A, B, C) і нараховується за формулою:

- тип A: Y = 100 · |F4(x) + 50|, податок 10%
- тип B: Y = 150 · |F5(x) + 100|, податок 15%
- тип C: Y = 100 · |F6(x) + 135|, податок 20%

де F4(x), F5(x), F6(x) задані згідно з варіантом (i = 1).

Користувач вводить x і тип робіт. Програма виводить нараховану суму, суму податку та суму до видачі.

Задачу розв'язано двома способами:
- з використанням повної команди розгалуження "if - else if - else";
- з використанням короткої команди розгалуження "if".
